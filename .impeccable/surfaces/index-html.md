# Concise primary workspace

- Scope and mode: the single web application surface; Operate.
- Audience and job: people with a local file and a specific crop, resize, trim, or conversion task who want an immediate private result.
- Primary action: open a local file, bring one tool forward, adjust against a live preview, and export.
- Content and proof: the working editor itself; the explicit local-only processing statement. No fabricated customer or usage proof.
- Constraints: responsive, keyboard accessible, light/dark themes, offline after load, no file networking, browser-native still-image operations, local multi-threaded ffmpeg for later media work.
- Chosen direction: Signal Queue — one bright, still working plane over an emissive void; inactive utilities recede through brightness, spacing, and slow dust-field depth.
- Memorable moment: dropping a file collapses the distant command queue and pulls the actual media into the fixed front plane without a page transition.
- Unresolved: trim and conversion are intentionally scaffolded after the crop/resize slice; video crop is fast-follow.
